TROUBLESHOOTING
───────────────

PROBLEMA: "Erro ao conectar ao banco de dados"
SOLUÇÃO:
  1. Verificar credenciais em banco/conexao_pdo.php
     • DB_HOST = localhost ✓
     • DB_USER = root ✓
     • DB_PASS = (vazio ou sua senha) ✓
     • DB_NAME = paradas ✓
  2. Iniciar MySQL
  3. Criar banco: CREATE DATABASE paradas;
  4. Executar setup.php novamente

PROBLEMA: "Tabelas não encontradas"
SOLUÇÃO:
  1. Abrir phpMyAdmin
  2. Selecionar banco "paradas"
  3. Executar SQL de banco/tabelas_novas.sql
  4. Ou executar setup.php

PROBLEMA: "Fatal error: Call to undefined function..."
SOLUÇÃO:
  1. Verificar que includes/functions.php existe
  2. Verificar que include/require está correto
  3. Verificar permissões da pasta includes

PROBLEMA: "Session expired"
SOLUÇÃO:
  1. É normal após 30 minutos
  2. Faça login novamente
  3. Para aumentar tempo:
     - Editar includes/auth.php
     - Mudar: $inatividade = 30 * 60;
     - Para: $inatividade = 60 * 60; (1 hora)

PROBLEMA: "Gráficos não aparecem"
SOLUÇÃO:
  1. Atualizar página: Ctrl+F5
  2. Verificar console (F12)
  3. Se erro de Chart.js:
     - Confirmar CDN disponível
     - Ou fazer download local

PROBLEMA: "Permissão negada em admin"
SOLUÇÃO:
  1. Fazer logout
  2. Fazer login com Administrador
  3. Ou verificar perfil do usuário
