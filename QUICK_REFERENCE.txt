FÓRMULAS IMPORTANTES:
────────────────────

🎯 OEE
   OEE = Disponibilidade × Performance × Qualidade
   
   Disponibilidade = Tempo Produzindo / (Tempo Produzindo + Tempo Parado)
   Performance = Produção Real / Produção Planejada
   Qualidade = Produção Boa / Produção Total

📊 Eficiência
   Eficiência = (Velocidade Real / Velocidade Planejada) × 100

✅ Qualidade
   Qualidade = (Produção Total - Perdas) / Produção Total × 100

TROUBLESHOOTING RÁPIDO:
──────────────────────

Problema              Solução
─────────────────────────────────────────────────────────────────────────────
Erro ao conectar      → Verificar credenciais em conexao_pdo.php
Tabelas não existem   → Executar setup.php
Sessão expirada       → Normal (30 min). Aumentar em auth.php
Gráficos não aparecem → Atualizar (Ctrl+F5). Verificar CDN
Login não funciona    → Verificar banco. Executar setup.php
Permissão negada      → Verificar perfil em admin/usuarios.php
Auditoria vazia       → Fazer ações no sistema

CHEAT SHEET SQL:
────────────────

# Ver usuários
SELECT * FROM usuarios;

# Ver auditoria (últimos 10)
SELECT * FROM auditoria ORDER BY data DESC LIMIT 10;

# Ver paradas do dia
SELECT * FROM paradas WHERE DATE(inicio) = CURDATE();

# Calcular OEE do dia
SELECT 
  (tempo_produzindo / (tempo_produzindo + tempo_parado)) * 100 as disponibilidade,
  (producao_real / producao_planejada) * 100 as performance,
  (producao_boa / producao_total) * 100 as qualidade
FROM dashboard_data WHERE DATE(data) = CURDATE();
